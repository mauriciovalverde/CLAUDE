# App Android do AMPARO

App Android (Capacitor) que abre https://familiaamparo.com.br em tela cheia. Como carrega o site ao vivo, toda atualização do site já aparece no app, sem gerar APK novo.

O APK é gerado sozinho pelo workflow `.github/workflows/apk.yml` (ao mudar algo nesta pasta ou manualmente em Actions → "Gerar APK Android") e publicado em:
https://github.com/mauriciovalverde/CLAUDE/releases/download/app-android/amparo.apk
